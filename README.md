# BERT-finetuning-dml
Final assignment for Deep Machine Learning, finetuning a BERT model for a (binary)classification problem


## Environment setup
```python -m venv <path to venv>```

MAC
```source <path to venv>/bin/activate```
Windows
```./env/Scripts/activate```

```pip install -r requirements.txt``` (Does not include pytorch)

Now install the correct version of pytorch for your system, ie windows/mac/linux, cuda/no cuda.
https://pytorch.org/get-started/locally/
